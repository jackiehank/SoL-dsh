# 面板行顺序对齐 README：融合、收纳、回执、压缩

## 问题

输入框下方面板当前的行顺序是「收纳、回执、压缩、融合」，与 README 和尾行里的
「融合、收纳、回执、压缩」不一致，读起来要先找行。

## 方案

只改 `plugin/client.js` 里 `rows` 的排列顺序，文案与数值不变：

1. 融合（次数，不折算 token）
2. 收纳
3. 回执
4. 压缩
5. 工具输出少写（百分比）

## 验收

- 面板展开后的行序与 README 的机制表一致；
- 数字与改前相同，仅顺序变化；
- `node --check plugin/client.js` 通过。
